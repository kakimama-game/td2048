下の2048で数字を合体させて
強いユニットを作ろう！

  1. 下の盤面をスワイプで同じ数字を合体
  2. タイルをタップして選ぶ
  3. 上のマップの緑のマスをタップで配置
    （配置したタイルは盤面から消える）
  4. 敵には弱点あり！「？」で一覧（例：🛡️装甲は💣爆発系だけ）
  5. 置いたユニットをタップで「撤去」できる
  6. 敵を城まで通すと❤️が減る。0でゲームオーバー

ヒント：じゃまなタイルは出撃させて盤面を空けよう。マスに置いたユニットより大きい数字なら上書きできます。
